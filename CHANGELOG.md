# KeyBindz changes

## 0.1.0

- Fork Omakeez with independent plugin, protocol, bridge and state identities.
- Add the detected Zenbook keyboard view and cards fallback.
- Follow Omarchy theme colors, rounding, borders, gradients and transparency.
- Add compositor frost, readable key surfaces and quieter unused keys.
- Add a 500 ms delay option and default to it; disable Shift/Alt triggers.
- Preserve drawer settings across shell reloads.

Original Omakeez release notes are retained in `docs/upstream/CHANGELOG.md`.
