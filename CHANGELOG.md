# KeyBindz changes

## 0.1.0

- Fork Omakeez with independent plugin, protocol, bridge and state identities.
- Add the detected Zenbook keyboard view and cards fallback.
- Follow Omarchy theme colors, rounding, borders, gradients and transparency.
- Add compositor frost, readable key surfaces and quieter unused keys.
- Add a 1 s hold delay and default to it, with 500 ms and shorter options; disable Shift/Alt triggers.
- Use charcoal key surfaces, transparent missing keys with soft outlines, and small keycap rounding, while keeping the compositor blur.
- Center key legends and commands, and give the spacebar a larger label and command size.
- Make the "None" top offset sit just beneath the top bar instead of leaving a large gap.
- Show System menu and Screenshot directly on the Esc and PrtSc keycaps, with compact actions on the rest of the top row.
- Use a proportional command font with a hairline divider under each key label for easier reading.
- Document the tested single-machine hardware scope, add current screenshots, and expand the installation and project-history notes.
- Preserve drawer settings across shell reloads.

Original Omakeez release notes are retained in `docs/upstream/CHANGELOG.md`.
